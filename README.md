# Zápočet

Pro zápočet z Algoritmizace je zapotřebí mít dostatek bodů z domácích úloh. Pro zápočet z Programování I je zapotřebí mít dostatek bodů z domácích úloh, úspěšně absolvovat zápočtový test a odevzdat a odprezentovat zápočtový program. Zápočet z Algoritmizace je nutný pro přihlášení na zkoušku.

# Účast

Účast na cvičeních je doporučená, ale není povinná. Za každý blok cvičení, na který přijdete, dostanete jeden bonusový bod (pro oba předměty), který se nepočítá do bodového maxima.

# Domácí úlohy

Všechny úlohy se odezvdávají přes ReCodEx (link viz výše). Pro Algoritmizaci i Programování I je zapotřebí mít alespoň 70% bodů (mimo bonusové úlohy).

# Zápočtový test

Zápočtový test proběhne na posledním cvičení. Opravné termíny budou k dispozici během zkouškového období. Dohromady máte na zápočtový test 3 pokusy.

# Zápočtové programy

Do konce roku se se mnou domluvte na tématu zápočtového programu. Pro návrhy bude na ReCodExu vytvořena speciální úloha, kde můžete nahrát textový dokument s popisem vašeho programu. Jakmile vám váš návrh odsouhlasím, tak na programu můžete začít pracovat (většinou to není problém, ale občas studenti navrhují příliš jednoduché či složité problémy). Pro inspiraci můžete použít následující linky:

* [Lenka Forstová](https://www.ms.mff.cuni.cz/~forstova/pgmZ/Zapoctaky.html)
* [Martin Mareš](http://mj.ucw.cz/vyuka/zap/)
* [Michal Žemlička](http://www.ms.mff.cuni.cz/~zemlicka/vyuka/NMIN101/namety/)

Případně si můžeme vymyslet téma vlastní. Součástí zápočtového programu je:

* **Implementace** - zdrojový kód
* **Testovací data** - ukázkový vstup a výstup
* **Uživatelská dokumentace** - jak se s vaším programem pracuje; pro Programování I stačí rozumně detailní README (ale jestli chcete, můžete dokumentaci poslat jako PDF, webovou stránku, atp.)
* **Programátorská dokumentace** - jak váš program funguje; pro Programování I stačí detailní dokumentační komentáře v kódu (v Pythonu se to dělá pomocí [docstringů](https://peps.python.org/pep-0257/))

Jako návod k psaní dokumentace můžete použít např. [toto](https://ksvi.mff.cuni.cz/~kryl/dokumentace.htm). Není to ale nic komplikovaného. Stačí se vžít do role uživatele (co všechno je zapotřebí vědět, aby váš program mohl plně využít) nebo jiného programátora (jaké všechny informace potřebuju, abych ve vašem programu něco změnil nebo přidal).

Jakmile máte všechny náležitosti hotové, tak mi jednoduše pošlete mail (na univerzitní adresu). Zápočtový program byste měli odevzdávat jako git repozitář (bude na přednášce). Jestli to bude na našem univerzitním gitlabu nebo na jiné platformě (např. GitHub) je mi celkem jedno. V mailu pak stačí jen uvést link na repozitář. Pokud bude vše OK, tak se domluvíme na prezentaci (osobně či online), kde mi váš program ukážete. Počítejte s tím, že mezi odezvdáním a prezentací je obvykle cca týden.

Deadline na odevzdání a odprezentování programu je konec zimního zkouškového období.
